# Mould King - MK 3.8

**Mould King - MK 3.8** ist ein Bluetooth-Low-Energy-Modul (BLE) mit drei integrierten Motoren und LEGO-kompatiblen Kreuzachsen sowie zwei elektrischen Mini-Steckverbindern.

![Mould King - MK 3.8](../../../../BrickController2/BrickController2/UI/Images/mk3_8_image.png)

## Kanäle

Das **Mould King - MK 3.8**-Modul stellt 5 Kanäle bereit:

| Kanäle | Zweck | Ausgabe |
|---|---|---|
| 1 | Linke Achse | -100 % bis +100 % |
| 2 | Stecker 1 | -100 % bis +100 % |
| 3 | Rechte Achse | -100 % bis +100 % |
| 4 | Stecker 2 | -100 % bis +100 % |
| 5 | Obere Achse | Links / aus / rechts |

## Erste Schritte

**Das Modul wird nicht durch die Suche gefunden.**

1. Öffne die Geräteliste, tippe auf ![](../../../icons/playlist_add.svg) **Geräte manuell hinzufügen**.
2. Aktiviere in der Liste zum manuellen Hinzufügen **Mould King - MK 3.8 Gerät**. Tippe anschließend auf ![](../../../icons/done_outline.svg) **Änderungen übernehmen**.
3. Schalte das **Mould King - MK 3.8**-Modul ein.
4. Verwende das Gerät in einer Kreation und weise seine Kanäle Steuerungsaktionen zu.

## Hinweise

- Die Ausgabe wird über Bluetooth-Werbenachrichten gesendet. Daher meldet das Modul weder einen Verbindungsstatus noch die Akkuspannung.
- Die Verbindungsnachricht wird erneut gesendet, nachdem alle Kanäle einige Sekunden lang auf null geblieben sind.

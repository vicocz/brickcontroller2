# LEGO WeDo 2.0 Smart Hub

Der LEGO WeDo 2.0 Smart Hub ist ein Bluetooth-LE-Hub mit zwei Motoranschlüssen.

![WeDo 2.0](../../../../BrickController2/BrickController2/UI/Images/wedo2_image.png)

## Kanäle

Das Gerät stellt 2 Kanäle bereit:

| Kanäle | Zweck | Ausgabe |
|---|---|---|
| 1 - 2 | Anschlüsse A, B | -100 % bis +100 % |

## Erste Schritte

1. Schalte den Hub mit seiner Taste ein.
2. Öffne die Geräteliste und tippe auf ![](../../../icons/search.svg) **neue Geräte scannen**. Gefundene Geräte werden zur Liste hinzugefügt.
3. Verwende das Gerät in einer Kreation und weise seine Kanäle Steuerungsaktionen zu.

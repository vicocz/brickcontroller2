# Kreation

Auf dieser Seite siehst du die Steuerungsprofile einer Kreation.

## Funktionen

- Steuerungsprofile hinzufügen, umbenennen, kopieren oder löschen.
- Öffne ein Profil, um seine Steuerungsaktionen einzurichten.
- Starte die Kreation, um dein Modell zu steuern.

## Symbolleiste

- ![](../../../icons/share.svg) **Kreation als Text teilen** – Teile die Kreation als Text.
- ![](../../../icons/upload_file.svg) **Kreation als Datei teilen** – Teile die Kreation als Datei.
- ![](../../../icons/file_download.svg) **Steuerungsprofil importieren** – Importiere ein Profil aus einer Datei.
- ![](../../../icons/file_upload.svg) **Kreation exportieren** (Überlaufmenü) – Exportiere die Kreation in eine Datei.
- ![](../../../icons/copy.svg) **Kreation in die Zwischenablage kopieren** (Überlaufmenü) – Kopiere die Kreation in die Zwischenablage.
- ![](../../../icons/paste.svg) **Steuerungsprofil aus der Zwischenablage importieren** (Überlaufmenü) – Füge ein kopiertes Profil ein.
- ![](../../../icons/help_outline.svg) **Hilfe** (Überlaufmenü) – Öffne diese Hilfeseite.

## Wischaktionen

- ![](../../../icons/play_arrow.svg) **Abspielen** – Starte die Kreation mit diesem Profil (nach links wischen).
- ![](../../../icons/copy.svg) **Kopieren** – Kopiere ein Profil (nach links wischen).
- ![](../../../icons/cancel.svg) **Löschen** – Lösche ein Profil (nach rechts wischen).

## Weitere Schaltflächen

- ![](../../../icons/add.svg) **neues Steuerungsprofil erstellen** – Tippe auf die schwebende Schaltfläche, um ein Profil hinzuzufügen.
- ![](../../../icons/play_arrow.svg) **Abspielen** – Starte die Kreation.

## Tipps

- Verwende mehrere Profile, um zwischen Steuerungsarten zu wechseln, zum Beispiel zwischen einer einfachen und einer detaillierten Steuerung.

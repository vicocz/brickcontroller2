# Geräte

Die Geräteliste enthält die Geräte, die du in Kreationen verwenden kannst.

## Gerät hinzufügen

Du kannst ein Gerät auf zwei Arten hinzufügen.

### Gefundene Geräte

Die meisten Geräte werden bei einer Suche gefunden.

1. Schalte das Gerät ein.
2. Tippe auf ![](../../../icons/search.svg) **neue Geräte scannen**.
3. Die gefundenen Geräte werden zur Liste hinzugefügt.

### Manuell hinzugefügte Geräte

Einige Geräte können nicht durch eine Suche gefunden werden. Sie verbinden sich nicht mit der App, sondern werden über Bluetooth Advertising gesteuert. Daher gibt es nichts, wonach gesucht werden könnte.

1. Tippe auf ![](../../../icons/playlist_add.svg) **Geräte manuell einfügen**.
2. Wähle die hinzuzufügenden Geräte aus. Entferne die Auswahl eines Geräts, um es wieder zu entfernen.
3. Übernimm die Änderungen.

Das manuelle Hinzufügen ist nur verfügbar, wenn das Telefon Bluetooth-LE-Werbenachrichten unterstützt. Geräte, die zusätzliche Hardware benötigen, wie der Power-Functions-Infrarotsender, werden nur angeboten, wenn das Telefon diese unterstützt.

### Welche Methode ist geeignet?

| Durch Suche hinzugefügt | Manuell hinzugefügt |
|---|---|
| SBrick, SBrick Light, BuWizz 2 | |
| BuWizz, BuWizz 3 | Mould King MK3, MK3.8, MK4, MK5, MK6 |
| LEGO®: Boost, Powered Up, Technic Hub, Technic Move, Duplo Train Hub, WeDo 2.0, Fernbedienung | JieStar SCM4, SCM8 |
| Circuit Cubes | Power Box M Battery, A Series |
| PFx Brick | Power-Functions-Infrarot |
| Mould King MK DIY, CaDA Race Car | |

## Wischaktionen

- ![](../../../icons/cancel.svg) **Löschen** – Entferne das Gerät aus der Liste (nach rechts wischen).
- ![](../../../icons/help_outline.svg) **Hilfe** – Öffne die Hilfe zum Gerät (nach links wischen).
- ![](../../../icons/settings.svg) **Einstellungen** – Öffne die Einstellungen des Geräts (nach links wischen).
- ![](../../../icons/edit.svg) **Umbenennen** – Benenne das Gerät um (nach links wischen).

# Sequenzen

Eine Sequenz ist eine wiederverwendbare Folge von Steuerungspunkten, mit der du den Ausgabewert eines Kanals automatisierst. Du kannst Sequenzen in einer Kreation den Steuerungsaktionen eines Steuerungsprofils zuweisen.

## Funktionen

- Füge mit der schwebenden Schaltfläche ![](../../../icons/add.svg) (**neue Sequenz erstellen**) eine Sequenz hinzu.
- Tippe auf eine Sequenz, um sie im [Sequenzeditor](../sequence-editor/README.md) zu öffnen.
- Wische bei einer Sequenz nach links, um sie ![](../../../icons/share.svg) **zu teilen**.
- Wische bei einer Sequenz nach rechts, um sie ![](../../../icons/cancel.svg) **zu löschen**.

## Symbolleiste

- ![](../../../icons/qr_code_scanner.svg) **QR-Code scannen** – Importiere eine geteilte Sequenz, indem du ihren QR-Code scannst.
- ![](../../../icons/note_add.svg) **Sequenz aus einer Datei importieren** – Importiere eine Sequenz aus einer Datei.
- ![](../../../icons/paste.svg) **Sequenz aus der Zwischenablage importieren** – Füge eine kopierte Sequenz ein.
- ![](../../../icons/file_download.svg) **Sequenz importieren** (Überlaufmenü) – Importiere eine zuvor exportierte Sequenzdatei aus dem gemeinsamen Speicherverzeichnis.
- ![](../../../icons/help_outline.svg) **Hilfe** (Überlaufmenü) – Öffne diese Hilfeseite.

# Supported devices

Devices with a help topic are linked. Other devices are supported by the app but not documented yet.

## LEGO

- Powered Up hub
- Boost Hub
- Technic Hub
- WeDo 2.0 Smart Hub
- Technic Move Hub (PLAYVM mode)
- Duplo Train Hub
- Power Functions infrared receiver (Android devices with an IR emitter)

- [Circuit Cubes](circuitcubes/README.md)
- JieStar 4 and 8 Channel Smart Creative Module
- Mould King DIY Module
- Mould King 3.0, 3.8 Powered Module
- [Mould King 4.0 Powered Module](mk4/README.md)
- Mould King 5.0, 6.0 Powered Module
- [PFx Brick](pfxbrick/README.md)
- PowerBox MBattery and A Series
- SBrick, SBrick Plus and SBrick Light

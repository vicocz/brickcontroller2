# LEGO Power Functions Infrared

The infrared device controls LEGO Power Functions receivers through the phone's infrared emitter (if available).

![Infrared](../../../../BrickController2/BrickController2/UI/Images/infrared_image.png)

## Channels

The device exposes 2 channels:

| Channels | Purpose | Output |
|---|---|---|
| 1 - 2 | Receiver outputs (A, B) | -100 % to +100 % |

## Getting started

1. Make sure the phone has an infrared emitter and the receiver is switched on.
2. Open the device list and press **Scan for new devices**. Found devices are added to the list.
3. Use the device in a creation: assign its channels to controller actions.

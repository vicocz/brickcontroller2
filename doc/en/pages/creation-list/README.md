# Creations

A creation represents one of your models together with the controller setup that drives it. This is the main page of the app.

## What you can do

- Add a new creation with the floating ![](../../../icons/add.svg) button (**Add a new creation**).
- Tap a creation to open it and edit its controller profiles.
- Swipe a creation to the left to ![](../../../icons/share.svg) **Share** or ![](../../../icons/play_arrow.svg) **Play** it.
- Swipe a creation to the right to ![](../../../icons/cancel.svg) **Delete** it.

## Toolbar

- ![](../../../icons/qr_code_scanner.svg) **Scan QR code** - import a creation shared by someone else by scanning its QR code.
- ![](../../../icons/note_add.svg) **Import a creation from file** - import a creation from a file.
- ![](../../../icons/settings.svg) **Settings** - open the application settings.
- ![](../../../icons/file_download.svg) **Import a creation** (overflow menu) - import a creation from text.
- ![](../../../icons/paste.svg) **Import a creation from clipboard** (overflow menu) - paste a creation copied to the clipboard.
- ![](../../../icons/help_outline.svg) **Help** (overflow menu) - show this page.

## Bottom navigation

- ![](../../../icons/hub.svg) **Devices** - scan for and manage your devices.
- ![](../../../icons/sports_esports.svg) **Input devices** - test connected game controllers and keyboards.
- ![](../../../icons/format_list_bulleted.svg) **Sequences** - manage reusable control sequences.
- ![](../../../icons/info.svg) **About** - application information.

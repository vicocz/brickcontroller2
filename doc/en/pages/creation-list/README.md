# Creations

A creation represents one of your models together with the controller setup that drives it. This is the main page of the app.

## What you can do

- Add a new creation with the floating **+** button.
- Tap a creation to open it and edit its controller profiles.
- Swipe a creation to the right to **Share** or **Play** it.
- Swipe a creation to the left to **Delete** it.

## Toolbar

- **Scan QR code** - import a creation shared by someone else by scanning its QR code.
- **Import from file** - import a creation from a file.
- **Settings** - open the application settings.
- **Import creation** (overflow menu) - import a creation from text.
- **Paste creation** (overflow menu) - paste a creation copied to the clipboard.
- **Help** (overflow menu) - show this page.

## Bottom navigation

- **Devices** - scan for and manage your devices.
- **Input devices** - test connected game controllers and keyboards.
- **Sequences** - manage reusable control sequences.
- **About** - application information.

# Creation

This page shows the controller profiles of a creation.

## What you can do

- Add, rename, copy or delete controller profiles.
- Open a profile to configure its controller actions.
- Start the creation to control your model.

## Toolbar

- ![](../../../icons/share.svg) **Share** - share the creation as text.
- ![](../../../icons/upload_file.svg) **Share the creation as file** - share the creation as a file.
- ![](../../../icons/file_download.svg) **Import a controller profile** - import a profile from a file.
- ![](../../../icons/file_upload.svg) **Export the creation** (overflow menu) - export the creation to a file.
- ![](../../../icons/copy.svg) **Copy the creation to clipboard** (overflow menu) - copy the creation to the clipboard.
- ![](../../../icons/paste.svg) **Import a controller profile from clipboard** (overflow menu) - paste a profile copied to the clipboard.
- ![](../../../icons/help_outline.svg) **Help** (overflow menu) - show this page.

## Swipe actions

- ![](../../../icons/play_arrow.svg) **Play** - start the creation with this profile (swipe it to the left).
- ![](../../../icons/copy.svg) **Copy** - copy a profile (swipe it to the left).
- ![](../../../icons/cancel.svg) **Delete** - delete a profile (swipe it to the right).

## Other buttons

- ![](../../../icons/add.svg) **Add a new controller profile** - floating button to add a new profile.
- ![](../../../icons/play_arrow.svg) **Play** - start the creation.

## Tips

- Use several profiles to switch between control schemes, for example a simple one and a detailed one.

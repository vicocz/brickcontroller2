# Input device tester

Shows the events sent by your connected gamepads and other input devices. Use it to check that a controller works and to find out which button or axis sends which event code.

## What you can do

- See the events of each connected input device, grouped by device ID and name.
- Check the event code, the current value and the event type of every button or axis you use.

## How to

1. Connect your gamepad.
2. Open **Input device tester**.
3. Press buttons or move the joysticks. The events appear in the list under the device.
4. Note the event code of the button or axis you want to use in a controller action.

## Notes

- The list is empty until you press a button or move a joystick.
- Each event code is listed once per device, with its latest value.
- If your gamepad does not show up, reconnect it and press a button again.

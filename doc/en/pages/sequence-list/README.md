# Sequences

A sequence is a reusable series of control points that automates the output value of a channel. Sequences can be assigned to controller actions in a creation's controller profile.

## What you can do

- Add a new sequence with the floating ![](../../../icons/add.svg) button (**Add a new sequence**).
- Tap a sequence to open it in the [sequence editor](../sequence-editor/README.md).
- Swipe a sequence to the left to ![](../../../icons/share.svg) **Share** it.
- Swipe a sequence to the right to ![](../../../icons/cancel.svg) **Delete** it.

## Toolbar

- ![](../../../icons/qr_code_scanner.svg) **Scan QR code** - import a sequence shared by someone else by scanning its QR code.
- ![](../../../icons/note_add.svg) **Import a sequence from file** - import a sequence from a file.
- ![](../../../icons/paste.svg) **Import a sequence from clipboard** - paste a sequence copied to the clipboard.
- ![](../../../icons/file_download.svg) **Import a sequence** (overflow menu) - import a sequence from text.
- ![](../../../icons/help_outline.svg) **Help** (overflow menu) - show this page.

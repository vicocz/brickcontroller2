# Sequences

A sequence is a reusable series of control points that automates the output value of a channel. Sequences can be assigned to controller actions in a creation's controller profile.

## What you can do

- Add a new sequence with the floating **+** button.
- Tap a sequence to open it in the [sequence editor](../sequence-editor/README.md).
- Swipe a sequence to the right to **Share** it.
- Swipe a sequence to the left to **Delete** it.

## Toolbar

- **Scan QR code** - import a sequence shared by someone else by scanning its QR code.
- **Import from file** - import a sequence from a file.
- **Paste sequence** - paste a sequence copied to the clipboard.
- **Import sequence** (overflow menu) - import a sequence from text.
- **Help** (overflow menu) - show this page.

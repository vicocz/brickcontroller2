# Creation

This page shows the controller profiles of a creation.

## What you can do

- Add, rename, copy or delete controller profiles.
- Open a profile to configure its controller actions.
- Start the creation to control your model.

## Tips

- Use several profiles to switch between control schemes, for example a simple one and a detailed one.
